# Safe Zone Patrol — Marketing

React + Vite marketing site. Visual result matches the original static HTML.

## Run

```bash
npm install
npm run dev
```

## Structure

- `src/components` — Header, Hero, Features, ZonePanel, Pricing, CTA, Footer, icons
- `src/pages/Home.tsx` — home page composition
- `src/styles.css` — original stylesheet
- `public/assets` — images and fonts
